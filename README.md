# Ideal for Claude Code

Run your Ideal (getonideal.com) from Claude: one account for your video, music, podcasts, posts and shop,
set up and published by your AI through Ideal's MCP server.

    claude plugin marketplace add getonideal/ideal
    claude plugin install ideal@ideal

Connect page and docs: https://getonideal.com/create/claude · Privacy: https://getonideal.com/privacy
